Маршрут вложений описывает, **в какие папки** складывать файлы той или иной модели. Вместо свалки «всё в одну кучу» вы получаете аккуратное дерево, например по заказам или лидам.

## Шаблоны папок

Путь задаётся двумя шаблонами:

- **Корневая папка** — общий контейнер, например «Заказы».
- **Папка записи** — имя папки под каждую запись, собранное из её полей (номер, название, клиент).

```
Заказы/
├── SO-000042 — ООО «Клиент А»/
│   ├── договор.pdf
│   └── счёт.pdf
└── SO-000043 — ООО «Клиент Б»/
    └── КП.docx
```

## Конструктор шаблона

Шаблон папки собирается из **полей модели** через удобный конструктор тегов — не нужно руками вписывать имена полей. Выбираете модель, затем кликаете нужные поля — они подставляются в шаблон.

> [!tip] Поле «Модель» в маршруте — это связь с реестром моделей: выбираете модель из списка, а не печатаете её имя. После этого конструктор знает, какие поля доступны для шаблона.

## Стратегии переименования

Когда данные записи меняются (например, у заказа сменился клиент), можно выбрать поведение: оставить папку как есть или переименовать/переместить, чтобы имя папки соответствовало актуальным данным.
