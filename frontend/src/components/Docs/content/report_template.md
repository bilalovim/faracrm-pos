Шаблон отчёта — это заранее подготовленный документ Word (.docx) с плейсхолдерами, вместо которых подставляются данные записи (заказа, лида). Так формируются коммерческие предложения, счета, договоры в едином стиле.

## Как пользоваться

- Загрузите шаблон .docx с метками полей.
- Свяжите шаблон с моделью (например, «заказ»).
- Из карточки записи сформируйте документ — система подставит значения и отдаст готовый файл.
