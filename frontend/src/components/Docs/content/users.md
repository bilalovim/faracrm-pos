Пользователи — сотрудники, работающие в системе. Здесь администратор заводит учётные записи и настраивает доступ.

## Ключевые поля

- **Роли** — что пользователь может делать с данными (см. «Роли и права»).
- **Рабочее место** — какие разделы-плитки ему видны (см. «Рабочие места»).
- **Домашняя страница** — куда попадает пользователь после входа.
- **Язык** интерфейса, **аватар**, настройки **уведомлений**.

> [!info] Администратор (флаг «Администратор») видит все разделы и данные в обход ограничений — рабочее место ему не назначается.
