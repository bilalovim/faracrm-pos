Системные параметры — глобальные настройки всей системы. В отличие от личных настроек пользователя, они действуют на всех и меняются администратором. Каждый параметр — это ключ и значение с описанием.

## Что здесь настраивается

- **Хранилище и вложения** — путь к локальному хранилищу, лимиты размера файлов, параметры кэша.
- **Почта и уведомления** — параметры рассылок, адреса по умолчанию.
- **Безопасность** — политики сессий, требования к паролю и пр.
- **Интерфейс и брендинг** — название, логотип, значения по умолчанию.
- **Производительность** — в т.ч. режимы пагинации списков (см. ниже).

## Пагинация больших списков

Некоторые справочники бывают очень большими. Для них предусмотрены разные режимы постраничной загрузки, включая **«бесконечную» (курсорную) пагинацию**: список подгружается порциями по мере прокрутки, вместо классических страниц с номерами. Это заметно ускоряет работу с длинными списками — браузер не тянет тысячи строк сразу.

> [!info] Если в справочнике включена бесконечная пагинация, при прокрутке вниз автоматически догружаются следующие записи. Управляется это соответствующим системным параметром.

> [!warning] Меняйте системные параметры осознанно — они влияют на всех пользователей. Перед изменением полезно понимать смысл конкретного ключа (он указан в описании параметра).
