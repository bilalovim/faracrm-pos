Вложения — это файлы, привязанные к записям и сообщениям: договоры, фото, документы, картинки из чатов. Все они хранятся единообразно и привязаны к «своей» записи (лиду, партнёру, заказу, сообщению).

## Где физически лежат файлы

Само место хранения задаёт **Файловое хранилище** (локальный диск, Google Drive или Яндекс.Диск) — см. отдельную статью. Раскладку по папкам задают **Маршруты вложений**.

## Превью и кэш

Для изображений формируются превью, чтобы списки и чаты открывались быстро. При облачном хранилище локально может держаться кэш — ускоряет повторный доступ, не таская файл из облака каждый раз.
