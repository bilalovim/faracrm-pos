**Рабочее место** — это набор приложений (плиток верхнего меню), который видит пользователь. Оно отвечает за **видимость разделов**, а не за права на данные (за данные отвечают роли).

## Как это работает

- Каждому пользователю назначается одно рабочее место.
- Рабочее место — это список приложений (Общение, CRM, Продажи, Файлы …).
- В меню и лаунчере видны только приложения из рабочего места.
- Базовое рабочее место «Сотрудник» назначается новым не-администраторам автоматически.

> [!info] Нет рабочего места — не видно приложений. Исключение — администратор: он видит всё в обход.

> [!tip] Если сотрудник не видит нужный раздел, но права (роль) у него есть — проверьте его рабочее место: скорее всего, туда не добавлено соответствующее приложение.
