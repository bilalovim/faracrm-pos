Раздел «Проекты» — управление задачами. Задачи группируются по проектам, двигаются по стадиям и распределяются между участниками.

## Основное

- **Стадии задач** — колонки доски (например, «В работе», «Готово»).
- **Теги** — метки для группировки/фильтрации.
- **Участники проекта** — кто имеет доступ и на кого назначаются задачи.
- **Виды.** Канбан по стадиям и диаграмма **Ганта** по срокам.
