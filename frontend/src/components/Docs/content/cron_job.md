Планировщик выполняет задачи по расписанию без участия человека: синхронизацию файловых хранилищ, проверку почты, обслуживающие операции.

## Основное

- У каждой задачи своё расписание (интервал).
- Задачу можно включить/выключить.
- Видна история и результат последнего запуска.

> [!warning] Отключайте фоновые задачи с пониманием последствий: например, выключив синхронизацию хранилища, вы остановите выгрузку файлов в облако.
